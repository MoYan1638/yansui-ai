STEP 1/3 · 模型接入

Agent 用哪个大脑？

两种接入方式，之后随时可以在设置里换。
API 接入 推荐
填入任意兼容 OpenAI 协议的服务（DeepSeek、智谱、OpenAI 等）。模型在云端跑，手机零负担，能力强。
本地部署 进阶
连接本机或局域网的 Ollama / LM Studio。数据不出设备，但要求较高配置，速度与电量有代价。
本地模式提示：7B 级模型建议 12GB+ 内存设备；生成速度约为 API 的 1/5~1/10，长时间运行显著耗电。首次启用前会再次确认。
